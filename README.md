# 🌈 Rainbow Catch — Arcade Adventure

A colorful arcade-style browser game built with pure HTML, CSS and JavaScript (Canvas). Catch falling gems, stars and coins, build combos, collect power-ups and level up!

## ✨ Features
- ⭐ Score, ❤️ lives and level system
- 🔥 Combo bonuses and power-ups (magnet, slow-motion)
- 🏆 Best score saved in the browser (localStorage)
- 📱 Responsive, works on desktop and mobile (touch controls)
- No installation or dependencies, just one `index.html`

## ▶️ How to Play
Open `index.html` in any modern browser and move the basket to catch the good items. Avoid the bad ones so you don't lose your lives!

## 🛠️ Built With
HTML5 · CSS3 · JavaScript (Canvas API)
